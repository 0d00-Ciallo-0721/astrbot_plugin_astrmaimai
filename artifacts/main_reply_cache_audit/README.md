# Main Reply Cache Audit

This directory is generated by `tests/manual/main_reply_cache_audit.py`.

Expected artifacts:

- `main_reply_cache_audit.json`: structured rows, findings, and extracted trace evidence.
- `main_reply_cache_audit.md`: human-readable deep analysis for the main reply path.

Scope:

- Only the main-reply path (`sys2/dialog`) is in scope.
- Background workloads such as `dream`, `profile`, `memory summary`, and `proactive` are excluded from the headline conclusion.

Key interpretation rules:

- `usage.input_cached` is the only positive evidence for real cache hit.
- `prefix_stable`, `cache_affinity_ready_rate`, and `provider_session_usage_rate` are readiness or topology indicators, not hit proof.
- Prompt shortening and cache hits must be reported separately.
