# Prompt 01：配置链核心断裂修复

## 任务目标
修复当前最核心的配置链断裂，优先解决“schema 有字段，但 `config.py` 模型无法承接，导致运行时静默回退默认值”的问题。

本轮只处理两件事：
- `conversation` 配置段缺少模型承接
- `deep_temporal_*` / `maintenance_*` 的 schema 命名空间与代码模型不一致

不要顺手扩改其他模块。

- `artifacts/review_new/13-汇总-AstrMai最终审查报告.md`

## 必读代码

- `astrmai/app/bootstrap.py`
- 任何直接读取 `config.conversation`、`config.memory.deep_temporal_*`、`config.memory.maintenance_*` 的调用点

## 必须完成的修复
1. 为 `conversation` 补齐真实配置模型承接。
2. 让 `_conf_schema.json` 与 `config.py` 对 `deep_temporal_*` / `maintenance_*` 的归属完全一致。
3. 确保下游读取点不再依赖“字段不存在时的静默默认值”。
